// ---------------------------------------------------------
// PIPELINE DATA FLOW CONNECTIONS
// ---------------------------------------------------------

// Stage 1: Retrieval Flow
Query > BM25 Sparse: "Biomedical Tokens"
Query > MedCPT Dense: "Query Encoder"
Corpus > BM25 Sparse
Corpus > MedCPT Dense: "Article Encoder"
BM25 Sparse > RRF: "Top-20 Sparse Ranks"
MedCPT Dense > RRF: "Top-20 Dense Ranks"
RRF > TopK Evidence: "Recall@5 = 1.000 (MRR = 0.991)"

// Stage 2: Generation Flow
Query > Prompt Builder
TopK Evidence > Prompt Builder: "Evidence Passages (K=3)"
Prompt Builder > Quantized LLM
Quantized LLM > LLM Output: "Raw Response Text"

// Extraction Flow
LLM Output > Decision Extractor
Decision Extractor > Final Decision: "Extracted Yes/No/Maybe"
LLM Output > Claim Segmenter
Claim Segmenter > Atomic Claims: "Prop Claims (>=5 tokens)"

// Stage 3: Verification Flow
Atomic Claims > NLI Cross Encoder
TopK Evidence > NLI Cross Encoder: "Passage Evidence Context"
NLI Cross Encoder > NLI Matrix: "[P_entail, P_neutral, P_contra]"
NLI Matrix > NLI Features: "Max-Pool Evidence Aggregation"

// Stage 4: Trust Fusion & Calibration Flow
TopK Evidence > Feature Fusion: "Retrieval Scores & Margin (3)"
LLM Output > Feature Fusion: "MiniLM Cosine Similarity (2)"
NLI Features > Feature Fusion: "Grounding Entail/Contra Signals (4)"
Feature Fusion > Trust Estimator: "Standardized 9-D Vector"
Trust Estimator > PostHoc Calibration: "Raw Log-Odds Probabilities"
PostHoc Calibration > Calibrated Trust Score: "AUROC = 0.7014"

// Clinical Safety & Audit Flow
Final Decision > Safety Gate: "Model Answer"
Calibrated Trust Score > Safety Gate: "Trust Score"
Safety Gate > Safe Region: "Trust >= 0.5 & Correct"
Safety Gate > Dangerous Failure: "Trust >= 0.5 & Incorrect (E5/E6)"
Safety Gate > Clinical Review: "Trust < 0.5 (Deferred to Clinician)"
